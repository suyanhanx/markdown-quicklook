# 图表阅读与稳定性

图表默认适应宽度。点击“实际大小”后可横向滚动；“放大”和“缩小”调整比例。

```mermaid
flowchart LR
  A[需求确认] --> B[设计结构] --> C[实现预览] --> D[功能检查] --> E[性能验证] --> F[打包安装] --> G[使用反馈] --> H[版本升级]
  C --> I[错误处理] --> E
  C --> J[图表缩放] --> E
```
